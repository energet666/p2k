proxychains-ng 4.17 portable build for x86_64 Linux

This package was built with a CentOS 7 based toolchain. It should run on
systems with glibc 2.17 or newer.

Quick start:

  ./proxychains4-local curl https://example.com

Default proxy configuration:

  etc/proxychains.conf

The bundled config points to a local HTTP proxy:

  http 127.0.0.1 3128

That matches px running locally on port 3128. Edit etc/proxychains.conf if your
local proxy uses another host, port, or protocol.

Notes:

  proxychains-ng uses LD_PRELOAD. It will not work for static binaries, setuid
  binaries, or programs that clear/prevent LD_PRELOAD.

  Use proxychains4-local from this directory. It passes the bundled config file
  explicitly and keeps the package relocatable.
